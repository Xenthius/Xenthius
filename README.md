# Hola, soy Franco 👋

Desarrollador y referente de sistemas en CABA, Argentina. Construyo portales web y automatizaciones, y trabajo con **Claude Code desde Visual Studio** para diseñar, probar y mejorar interfaces y backends más rápido y con más calidad.

## En qué ando

- 🛰️ **Entorno de antenas Starlink**: aporte al desarrollo del ambiente junto con el equipo de Infraestructura de mi empresa.
- 📦 **App de Remitos** *(privado)*: seguimiento de envíos entre sucursales con QR, firma digital, recepción con diferencias por ítem, roles por nodo y PWA instalable. Node, Express y SQLite.
- 🩺 **Portal Clínico** *(privado)*: gestión de pacientes y sesiones para profesionales de la salud, con aprobación de cuentas, reglas de seguridad por usuario y sincronización en la nube. React, Vite y Firebase.
- 📰 **Portal de IA**: noticias reales de inteligencia artificial con pipeline automático y sin costo de tokens. [portaldeia.web.app](https://portaldeia.web.app)
- 📅 **Calendario compartido** y 🏠 **app de tareas del hogar**.

## Cómo trabajo

- Rediseño de interfaces con identidad propia, accesibles y pensadas para el celular.
- Seguridad primero: permisos por rol y por nodo, sesiones controladas, datos sensibles fuera del código.
- Pruebas automatizadas y despliegues verificados antes de publicar.
- IA como herramienta de ingeniería: Claude Code en Visual Studio como par de desarrollo.
